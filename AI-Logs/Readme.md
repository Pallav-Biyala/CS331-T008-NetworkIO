## Summary of AI Usage

AI tools were used as supplementary assistance during the development and documentation of this project. The primary implementation, experimentation, testing, and evaluation were carried out and verified by the project team.

The main areas where AI assistance was used include:

1. **Technical Understanding:** Clarifying concepts related to network programming, TCP communication, HTTP file transfer, and I/O multiplexing mechanisms such as `select`, `poll`, `epoll`, and `io_uring`.

2. **Debugging Assistance:** Understanding compiler errors, runtime issues, and potential implementation problems. Suggested fixes were reviewed and tested by the team before being adopted.

3. **Documentation and Report Writing:** Improving the structure, clarity, and readability of technical explanations, implementation descriptions, experimental observations, and report sections.

4. **Benchmarking and Analysis:** Assistance in interpreting benchmark results, understanding performance metrics, and presenting experimental findings. Actual measurements were obtained through the team's experiments.

5. **Repository and Git Assistance:** Guidance on Git operations, repository organization, branch management, and project submission structure.
