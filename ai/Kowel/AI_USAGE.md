# AI Usage Guide — Conversation References

## Purpose

This file is the entry point for an AI assistant working with the conversations listed below.

The linked conversations are the primary source material. Use them to recover context, understand prior reasoning, identify decisions, and continue the work without making the user repeat established information.

## Instructions for the AI assistant

1. **Read the source conversations first.** Open and review every accessible link before giving project-specific advice or proposing changes.
2. **Treat conversation history as context, not unquestionable truth.** Distinguish:
   - Established decisions
   - Tentative proposals
   - Open questions
   - Assumptions that still need verification
3. **Preserve decision history.** When summarizing, retain the rationale, constraints, alternatives considered, and consequences—not just the final choice.
4. **Do not invent missing details.** If a link is inaccessible or a conversation does not establish a fact, say so explicitly.
5. **Resolve conflicts carefully.** Prefer the most recent explicit decision when conversations disagree, but flag meaningful contradictions for confirmation.
6. **Avoid redundant questions.** Use the linked history to answer questions about prior choices and work before asking the user to repeat information.
7. **Keep this file as the index.** Add new conversation links here when they become relevant, with a short descriptive label and date if known.

## Source access note

These links point to externally hosted shared conversations. Their availability and accessibility depend on the sharing settings and the AI assistant's browsing or retrieval capabilities. If a link cannot be opened, ask the user for an export or pasted transcript rather than guessing its contents.

## Updating this index

When adding a conversation:
- Add its shared URL under the appropriate platform.
- Give it a short descriptive title when the topic is known.
- Add the date when it is known.
- Remove duplicate URLs.
- Do not replace the original conversation links with an AI-generated summary.
