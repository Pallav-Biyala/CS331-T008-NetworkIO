Summary of AI Usage
AI tools were used as supplementary assistance during the development of
this project. The primary implementation, experimentation, testing, and
evaluation were carried out and verified by the project team.

The main areas in which AI assistance was used include:
1. Conceptual clarification: Understanding I/O mechanisms and
   related operating system concepts.
2. Decision-making support: Exploring technical trade-offs,
   comparing design alternatives, and evaluating their implications.
3. Code assistance: Supporting code development, debugging, and
   understanding implementation details.
Disclosure
AI tools supported the team's learning, development, debugging, and
documentation processes. They did not replace the team's implementation
work, experimental execution, verification, or responsibility for the
final submission. The project team remains responsible for the
correctness and integrity of all submitted work.
